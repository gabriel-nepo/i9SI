# i9SI - Data Visualization para posto de combustível

Sistema web voltado para proprietários de postos de combustíveis, com foco na visualização clara e interativa de dados de vendas. A aplicação exibe diversos gráficos alimentados por uma API que disponibiliza informações em arquivos JSON. O projeto foi implementado em JavaScript e desenvolvido durante um Hackathon promovido pelo ICEA Tech — evento de tecnologia realizado na UFOP/JM e organizado pela ClubPetro, uma aceleradora especializada em resultados para o setor de combustíveis.

Acesse aqui: https://gabriel-nepo.github.io/i9SI/
